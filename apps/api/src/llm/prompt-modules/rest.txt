## Scene Module: Rest

The player is taking a short or long rest. Handle mechanically:
- Short rest (1 hour): player may spend Hit Dice to recover HP; call `take_short_rest`
- Long rest (8 hours): full HP recovery, spell slot recovery, ability reset; call `take_long_rest`
- Long rest triggers the world tick; do not use any other rest tool for long rests
- Describe the rest environment — safe camp, uncomfortable shelter, or risky exposure
- Allow brief conversation, journaling, or planning during the rest period
- If interrupted by a random encounter, call `set_scene_type` to COMBAT
